# Bandwidth and false discovery in conditional stock-return densities

Pattern-finding on stock data behaves like an under-smoothed density estimate, which can turn noise into peaks that look like tradable edges. This study asks how much of the "edge" found in conditional stock-return densities comes from the bandwidth choice rather than real predictability. The method fits a 2D Gaussian KDE of the overnight gap against the forward 5-day market-relative return for current S&P 500 constituents (2000 to 2025), sweeps the bandwidth from 0.25x to 4x the cross-validated value, and compares an in-sample "pattern hunter" and a walk-forward test against 500 within-date shuffled placebos per bandwidth; the full design is in [PREREG.md](PREREG.md) and the 2026 holdout is locked. **Status: setup.**
